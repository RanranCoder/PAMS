# 党务管理系统（PAMS）设计方案

## 一、业务体系（基于真实材料梳理）

材料源：`D:\StudyFiles\Office\党建办公室\信工党建办公室历届资料\信工党建第九届\年度部门材料汇总`（约1660份，三个部门）。

| 部门 | 业务定位 | 核心产出 |
|---|---|---|
| 组织部 | 策划统筹 + 党务台账 | 策划书、座位表、议程表、水牌、礼品清单、入党积极分子/发展对象/函调/党员名单、党务系统录入 |
| 文秘部 | 活动执行与会务 | 签到表、值班排班、控烟安排与考勤、无课表、发票报销、素拓加分、新闻稿 |
| 新媒体中心 | 宣传内容 | 活动前预热推文、活动后推文、新闻稿、宣传视频 |
| 青年科技部 | 媒体影像 | 活动 PPT、罗洞志愿摄影、照片归档 |

核心业务实体是「活动」，一场活动串起四个部门。另有例行事务（每周控烟排班+考勤、办公室值班、无课表）和党务台账（入党申请→积极分子→发展对象→党员，各期名单+函调档案）。

## 二、活动全流程（指挥链，五步闭环）

```
① 指导老师下达任务
   ↓
② 主任绘制甘特图，分解任务、分发到各部门
   （任务/负责人/起止时间/依赖关系/里程碑）
   ↓
③ 组织部编制策划书 → 指导老师/主任审核通过
   （成为全部门工作的唯一依据）
   ↓
④ 各部门围绕策划书并行执行（按甘特图推进）
   ├─ 组织部：现场统筹、座位表、议程表、评分表
   ├─ 文秘部：签到、值班、物资、发票、素拓
   ├─ 新媒体中心：预热推文(活动前) → 报道推文/新闻稿(活动后)
   └─ 青年科技部：活动PPT、摄影安排
   ↓
⑤ 活动执行 → 总结 → 自动归档
```

活动状态机：任务下达 → 排期(甘特图) → 策划书编制 → 策划书审核 → 执行中 → 已结束 → 已归档。

## 三、技术栈

| 层 | 选型 |
|---|---|
| 前端 | React 18 + Vite + TypeScript + Ant Design 5（CSS变量定制）+ 自研 liquid glass 设计系统 |
| 后端 | Spring Boot + Spring Security(JWT) + MyBatis-Plus + MySQL 8 |
| 数据库 | `pams_db` |
| 部署 | 先本地单机运行（localhost），预留上线切换 |
| 存储 | 本地文件系统 `uploads/` + 附件表 |

## 四、UI 设计（liquid glass / Apple 风格 + 党务配色）

- 毛玻璃卡片：`backdrop-filter: blur + saturate`、半透明描边高光、悬浮辉光动效
- **明暗双主题**：暗色（近黑背景+白玻璃卡片）/ 亮色（白/浅灰背景+深玻璃卡片），一键切换
- **黑白为主色 + 国旗红强调色**（#DE2910 五星红旗标准红，可微调）；主按钮/进度条/今日线/强调文字/选中态用国旗红，其余黑白灰层级
- 自研甘特图：SVG 时间轴/任务条/依赖连线，拖拽起止、进度%、里程碑、今日线(红)，完全贴合玻璃风格

## 五、数据库设计（基于45份真实材料抽取字段）

核心表分组：
1. **用户组织**：`sys_user`、`sys_department`、`sys_role`（6角色+部门数据权限）
2. **活动管理**：`activity`、`activity_plan`(策划书章节/经费预算)、`activity_agenda`(议程)、`seat_map`(座位表)、`score`(评分表)、`signin`(签到)、`task`(甘特图任务：活动/名称/负责部门/负责人/起止/前置任务/里程碑/进度/状态)
3. **例行事务**：`schedule`(排班)、`attendance`(考勤)、`free_schedule`(无课表)
4. **党务台账**：`party_member`、`party_stage`(身份流转)、`party_roster`(名单)、`party_investigation`(函调)、`party_register`(党务录入)、`party_transfer`(组织关系转移)
5. **内容宣传**：`article`(推文)、`news`(新闻稿)
6. **档案资产**：`material`(归档)、`template_asset`(模板库)、`credit_record`(素拓加分)、`file`(附件)、`announcement`(通知)

## 六、功能模块（第一期全量）

1. 仪表盘（待办/本周排班/活动日历/各部门进度）
2. 活动管理（建档→甘特图→策划书→签到→推文→新闻稿→归档全流程，含审批）
3. 排班考勤（控烟每周排班、值班、摆摊、考勤统计）
4. 党务台账（入党申请→积极分子→发展对象→党员流转、各期名单、函调档案、党务录入、组织关系转移；敏感名单单独授权）
5. 新媒体管理（推文撰写/审核/发布、新闻稿管理）
6. 素拓加分（活动/答题加分登记与统计）
7. 模板资产库（水牌/座位表/策划书/LOGO 可复用）
8. 材料归档（按活动/类型/部门归档、检索、预览，替代手工"12月26日"汇总包）
9. 通知公告（发布与已读）
10. 用户权限（角色管理、部门数据权限、敏感数据授权）
